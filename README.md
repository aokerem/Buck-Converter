# Buck Converter

STM32F303K8 buck converter project: firmware, schematic, and bench notes.

- Firmware and build setup: [`firmware/`](firmware/README.md)
- Bench measurements: [`acik_cevrim_olcumleri.md`](acik_cevrim_olcumleri.md)
- Schematic: [`stm32 f303k8/devre/60W Buck Sematik.pdf`](stm32%20f303k8/devre/60W%20Buck%20Sematik.pdf)
